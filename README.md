# LinkedIn Clone

Early scaffold (Django). Apps: `accounts` (users/profiles), `feed` (posts).

    pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver

Features and stack are still to be decided.

## Roadmap (draft)

Planned, not yet built:

- Profiles (headline, about, experience, education, skills)
- Feed (posts, likes, comments)
- Connections and messaging
- Jobs board and applications
- Search, notifications, company pages

Open decisions (stack, hosting, media storage) are tracked in issues.
